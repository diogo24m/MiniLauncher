# Preparar MiniLauncher para F-Droid

Este documento é um rascunho para a primeira versão, **MiniLauncher 0.1.0** (código **1**, pacote `com.mini.launcher`). O projeto é um fork GPL-3.0 do [StradaOS 2.20.1](https://github.com/lordnordic-debug/StradaOS), de lordnordic-debug.

As alterações do fork incluem dados CAN/SPD do BMW MINI, velocidade SPD com GPS de reserva, seletor Bluetooth/Reprodutor, controlos ADB, identidade MINI, português de Portugal e tamanho de texto de 85 a 150%.

## Ficheiros e referências

- Metadados: [com.mini.launcher.yml](com.mini.launcher.yml).
- Descrições, ícones e notas: [fastlane](../../fastlane/metadata/android/).
- Notas da primeira versão: [0.1.0](../../changelogs/0.1.0.md).
- Código: https://github.com/diogo24m/MiniLauncher.
- Compilação e assinatura: [CONTRIBUTING.md](../../CONTRIBUTING.md).
- Dados e permissões: [PRIVACY.md](../../PRIVACY.md).

Antes de uma candidatura, preencher o build com o commit efetivo da versão publicada e, se aplicável, a chave de assinatura do MiniLauncher. Os metadados não incluem builds nem chaves de versões do projeto de origem.

As atualizações GitHub são opcionais para instalações de lojas F-Droid. Os metadados declaram NonFreeNet devido às alternativas de mapas Esri e de geocodificação BigDataCloud.
