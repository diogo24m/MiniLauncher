# Preparar MiniLauncher para IzzyOnDroid

Rascunho da primeira versão: **MiniLauncher 0.1.0**, código de versão **1**. O projeto é um fork GPL-3.0 do [StradaOS 2.20.1](https://github.com/lordnordic-debug/StradaOS), de lordnordic-debug.

- Repositório: https://github.com/diogo24m/MiniLauncher.
- Pacote: `com.mini.launcher`.
- APK previsto: `MiniLauncher-0.1.0.apk`, na etiqueta `v0.1.0`.
- Descrições e imagens: [fastlane](../../fastlane/metadata/android/).
- Notas: [0.1.0](../../changelogs/0.1.0.md).
- Privacidade e permissões: [PRIVACY.md](../../PRIVACY.md).

O MiniLauncher inclui mapas online/offline, atalhos Android Auto/CarPlay, dados CAN/SPD BMW MINI, velocímetros com prioridade SPD e GPS de reserva, seletor Bluetooth/Reprodutor, controlos ADB e personalização do início. As alterações relativamente à base são descritas em [MINILAUNCHER.md](../MINILAUNCHER.md).

A compilação release pode ser assinada com a chave do MiniLauncher através das variáveis documentadas em [CONTRIBUTING.md](../../CONTRIBUTING.md). Confirmar a publicação do APK e a assinatura antes de apresentar a candidatura.
